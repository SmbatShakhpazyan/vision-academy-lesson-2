# Vision Academy · Lesson 2

An Armenian interactive book on numerical sequences by Սմբատ Շախբազյան.

- 87 pages, 223 recall cards and 107 diagrams.
- Hover over linked terms and symbols for definitions and theorems.
- Click to pin a recall; tap on mobile.
- Search by term, notation or number.
- Everything is embedded in `index.html`; no backend or external assets are required.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository, for example `vision-academy-lesson-2`.
2. Upload `index.html`, `.nojekyll`, `PDFJS_LICENSE.txt` and `FONT_LICENSE.txt` to the root of `main`.
3. In **Settings → Pages**, choose **Deploy from a branch → main → / (root)** and save.
4. Open the address shown in GitHub Pages settings after deployment finishes.

A project site normally uses `https://USERNAME.github.io/REPOSITORY/`.
The book is available to everyone with the link. It has no login or paywall.
